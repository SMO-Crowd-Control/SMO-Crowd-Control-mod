# SMO Crowd Control

Welcome to **SMO Crowd Control**, a Super Mario Odyssey mod developed by **Zyric, WibiDev, and Growl**.

Control Mario using a Windows dashboard and let your Twitch viewers trigger gameplay effects through Channel Point rewards!

## Requirements

- A Nintendo Switch running a compatible Atmosphère custom firmware setup / Emulator
- Super Mario Odyssey
- A Windows PC
- A network connection between your Switch and PC
- A Twitch account (for Twitch integration)

## Installation

### Step 1 – Install the Switch Mod

1. Download the latest SMO Crowd Control Solo Edition ZIP.
2. Extract the downloaded ZIP on your PC.
3. Turn off your Nintendo Switch and access its microSD card.
4. Find the `atmosphere` folder in the extracted files.
5. Copy that folder to the root of your Switch SD card.
6. Merge folders if prompted, and back up existing mod files before replacing anything.
7. Insert the SD card and start your Switch with Atmosphère.
8. Launch Super Mario Odyssey.

**Important:** Remove conflicting or older SMO Crowd Control installations before launching the game.

### Step 2 – Start the Dashboard

The download includes the **SMO Crowd Control Dashboard as a Windows executable (.exe)**.

You do not need to install Python or compile the dashboard yourself.

1. Launch the included Dashboard `.exe`.
2. Wait for the dashboard to open.
3. Configure it like you want

### Step 3 – Connect to Your Switch

1. Connect your Switch and Windows PC to the same local network.
2. On your Switch, open **System Settings → Internet** and find your console's IP address.
3. Enter that IP address in the dashboard under **Switch IP**.
4. Set the port to **5050** unless your installation documentation specifies otherwise.
5. Click **CONNECT SWITCH**.
6. Wait until the dashboard shows that your Switch is connected.

Keep Super Mario Odyssey running while connecting.

### Step 4 – Set Up Twitch

To use Twitch Channel Points:

1. Click the Twitch login button in the dashboard.
2. Follow the authorization instructions.
3. Select your Twitch channel.
4. Configure the Crowd Control effects you want viewers to redeem.
5. Start Crowd Control in the dashboard when the connection and settings are ready.

Your viewers can now trigger supported effects through Twitch.

Some Twitch features require the appropriate account permissions.

## Troubleshooting

**Dashboard cannot connect to the Switch**

- Make sure your Switch and PC are on the same local network.
- Check that you entered the correct Switch IP address.
- Make sure the port is set to 5050.
- Make sure Super Mario Odyssey is running.
- Check whether your PC firewall or network configuration is blocking the connection.

**Twitch rewards are not working**

- Check your Twitch login and permissions.
- Make sure Crowd Control is started in the dashboard.
- Verify that reward names match your configured events.
- Check the dashboard activity log for errors.

**Game crashes or the mod does not load**

- Check your Atmosphère installation.
- Remove conflicting or older mod files.
- Verify that you installed the files from the same release.
