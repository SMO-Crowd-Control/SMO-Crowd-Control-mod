# SMO Crowd Control

SMO Crowd Control connects Twitch Crowd Control events with Super Mario Odyssey on the Nintendo Switch.

## Requirements

- Nintendo Switch with Atmosphere
- Super Mario Odyssey
- Twitch account with permission to create or change channel point rewards
- PC and Switch on the same network

## Installation

1. Download the latest **.zip release** from the Releases page.
2. Extract the ZIP.
3. Copy the included **atmosphere** folder to the root of your Switch SD card.
4. Start the Switch with Atmosphere.
5. Run the `.exe` from the Releases page on your PC.
6. Enter the Switch IP and port, then click **Connect Switch**.
7. Click **Connect Twitch** and follow the instructions in the browser window that opens.
8. Configure the events as you want.
9. Click **Start** to enable the events and automatically create the channel point rewards.
10. Have fun!

## Features

- Twitch integration
- Crowd Control events
    - Jump
    - Cappy throw
    - Crouch
    - Spam Jump
    - Moon Gravity
    - Random Gravity
    - First Person
    - Set Life to 1
    - Remove Oxygen
    - Disable Jump
    - Invincible Mario
    - Kill Mario
    - Give/remove moons
    - Give/remove coins
- Configurable event duration
- Save/load Switch IP and port
- Config files stored in `/configs` next to the server program
- Customizable event queue window for OBS
